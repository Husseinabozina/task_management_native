# ACCEPTANCE_CHECKLIST — قائمة القبول الشاملة (V1 + C1)

نفّذ بالترتيب وسجل النتيجة (✅/❌ + وصف). أي ❌ انسخ نص الخطأ أو صوّر الشاشة.
بيئة الاختبار: Xcode ⌘R على iPhone 17 Pro (DerivedData على الخارجي).

## أ) الإقلاع والبيانات (مرة واحدة — الأهم)

- [ ] **A1** التطبيق يبنى ويشتغل من غير errors (أول بناء يختبر migrations تلقائية: isPinned + reminderDate)
- [ ] **A2** بياناتك القديمة موجودة (مهمة «يلا» ومشروع التجربة 🚀)
- [ ] **A3** اقفل التطبيق وافتحه → البيانات لسه موجودة (حفظ دائم)

## ب) الرئيسية

- [ ] **B1** الجرس 🔔: نقطة بنفسجية عند وجود متأخرات، بدون نقطة لو مفيش
- [ ] **B2** «أهم المشاريع شغالة»: كارت/كارتين بألوان pastel وشريط تقدم
- [ ] **B3** «مهام النهارده»: أول 3 مفتوحة + إتمام سريع من هنا يشتغل
- [ ] **B4** «مشاريعك»: كل المشاريع + النسب؛ ضغطة تفتح مهام المشروع
- [ ] **B5** قسم فاضي يختفي تمامًا (مثلاً امسح كل المشاريع المؤقتة)

## ج) شاشة مهامي

- [ ] **C1** البحث: اكتب جزء من عنوان → نتايج فورية؛ امسح → ترجع كلها
- [ ] **C2** فلتر الأولوية: «مستعجلة» يعرض المستعجلة فقط
- [ ] **C3** شغالة عليها: غيّر حالة مهمة من المحرر → pill برتقالي + تظهر في فلتر «شغالة» + تُحتسب متأخرة لو موعدها فات
- [ ] **C4** تثبيت 📌: مهمة مثبتة تظهر أول القائمة (وعليها 📌)
- [ ] **C5** ضغطة على صف → شاشة قراءة: الوصف منسق (جرب **نص عريض** وقوائم) + كل البيانات
- [ ] **C6** من القراءة: «تعديل» يفتح المحرر بالبيانات؛ الحذف بتأكيد يمسح فعلًا

## د) التقويم والمشاريع

- [ ] **D1** التقويم: الشهر صح + أيام الأسبوع تبدأ بالسبت + عدّاد لكل يوم
- [ ] **D2** ضغطة يوم → مهامي مفلترة عليه
- [ ] **D3** المشاريع: إنشاء مشروع بالإيموجي واللون يشتغل ويظهر
- [ ] **D4** حذف مشروع: تأكيد + مهامه تنتقل لـ«بدون مشروع» (مش بتتمسح)

## هـ) التذكيرات 🔔

- [ ] **E1** مهمة بموعد → فعّل التذكير → أول مرة يطلب إذن الإشعارات (اقبله)
- [ ] **E2** ظبط التذكير بعد دقيقتين → اقفل التطبيق → **الإشعار يوصلك في المعاد** 📬
- [ ] **E3** تمت المهمة أو اتمسحت → مفيش إشعار جاي في المعاد
- [ ] **E4** مهمة من غير موعد → مفيش كارت تذكير أصلًا

## و) السحابة ☁️ (C1 — بعد ما Supabase جاهز: مشروعه اتعمل والسكيما اتطبقت والـ plist متملأ)

- [ ] **F1** أيقونة ☁️ ظاهرة في رأس الرئيسية → تفتح «الحساب والمزامنة»
- [ ] **F2** حساب جديد بالإيميل → رسالة تأكيد → فعّل → دخول ناجح
- [ ] **F3** «مزامنة الآن» → نجاح بدون خطأ + ظهور «آخر مزامنة»
- [ ] **F4** نسخة احتياطية تلقائية: ملفات في Documents/Backups (عن طريق Files app أو Xcode)
- [ ] **F5** Supabase ← Table Editor ← tasks: مهامك موجودة
- [ ] **F6** عدّل مهمة واعمل مزامنة → التغيير ظهر في الجدول
- [ ] **F7** امسح مهمة واعمل مزامنة → deleted_at اتملى (tombstone)
- [ ] **F8** إعادة جولة الترحيب: من ☁️ ← أسفل الشاشة → شاشة «يلا نبدأ» تظهر تاني

## ز) الدارك مود 🌙

- [ ] **G1** ⇧⌘A في السيميوليتر → كل الشاشات مقروءة (نصوص، كروت، pills، التقويم)
- [ ] **G2** رجّع Light واتأكد إن مفيش حاجة اتلخبطت

## معايير الإغلاق

كل البنود ✅ = **V1 تتقفل رسميًا** ونفتح باب C2 (تصلّب المزامنة) / C3 (الفريق) / أندرويد.
أي ❌ = انسخ التفاصيل وارجع — الإصلاح له أولوية مطلقة قبل أي ميزة جديدة.
