# أندرويد — نسخة العرض المحلية (A1–A2)، 2026-10-07

## النطاق المعتمد — D27

المستخدم وافق على إصلاح البناء والتخزين، ثم تنفيذ واجهات أندرويد وربطها ببيانات محلية حتى تصلح للصور والفيديو. التذكيرات والمزامنة خارج هذه المرحلة. تعديل iOS السابق محفوظ كما هو. البناء الآلي assembleDebug مفوض ضمن «إصلاح البناء»؛ لا تثبيت أو تشغيل جهاز/محاكي.

## معايير القبول قبل الكود

1. إصلاح أخطاء A1 الحقيقية: SQL وأسماء الأعمدة، استيرادات العقود، enum priority، تعديل نماذج immutable باستخدام copy. الحفاظ على UUID والتاريخ المحلي والحالات الثلاث.
2. عمليات التحديث/الحذف متعددة الجداول داخل transaction؛ حذف مشروع ينقل مهامه إلى بدون مشروع، وإتمام مهمة يضبط completedAt ويُلغيه عند إعادة الفتح.
3. ترحيب مرة واحدة بفصحى بسيطة وصورة iOS الجديدة بلا ذوات أرواح، وإمكانية إعادة الترحيب.
4. أربعة تابات حقيقية: الرئيسية، التقويم، المهام، المشاريع؛ زر إضافة وسط الشريط يفتح محررًا حقيقيًا.
5. الرئيسية: تقدم اليوم من البيانات، مؤشر متأخرات، أبرز مشروعين، مهام اليوم، صفوف المشاريع. إخفاء الأقسام الخالية كما في iOS.
6. المهام: بحث بالعنوان وحالة وأولوية ومشروع ويوم؛ الكل + سبعة أيام؛ إضافة سريعة؛ إتمام/إعادة فتح؛ حالة فارغة مختلفة عن نتائج الفلترة.
7. محرر المهمة: عنوان ووصف وحالة وأولوية وتثبيت وموعد ومشروع؛ تفاصيل بقراءة الوصف مع Markdown بسيط؛ تعديل وحذف بتأكيد. حفظ draft عند فشل الحفظ، ومنع double-submit.
8. المشاريع: إنشاء بإيموجي ولون من لوحة iOS، فتح مهام المشروع، حذف بتأكيد مع الاحتفاظ بالمهام.
9. التقويم: 42 خلية تبدأ بأول يوم الأسبوع المحلي، عدادات المفتوحة، تنقل الأشهر، اليوم يفتح مهامه؛ dueDay لا ينزلق بسبب timezone.
10. RTL وفاتح/داكن وخط Cairo وأصول الأيقونات وأشكال SVG المخصصة من المصدر المحلي؛ لا أزرار لتذكيرات أو مزامنة غير منفذة.
11. لا بيانات عرض تزرع تلقائيًا في قاعدة المستخدم؛ يمكن إنشاء البيانات يدويًا من الشاشات الحقيقية.

## الحقائق والثوابت

- HEAD الأساسي ae98903، أندرويد شاشة مؤقتة وA1 غير قابل للبناء. iOS مرجع التنفيذ المحلي؛ SCREEN_PLAN القديم يُقرأ مع D18/D20/D26.
- الأصول المرئية موجودة، والصورة الجديدة في كتالوج iOS. اللون الأساسي #5F33E1 وخط Cairo.
- البيانات تبقى في Room بنفس قاعدة v1؛ لا migration هدّامة أو reset أو upgrade.
- أثر التغيير: android/ + توثيق فقط. المخزن الحالي يستخدم val مع إعادة إسناد وenum compareTo محظور، فلا يكفي تعديل SQL وحده.

## التحقق وحدوده

مراجعة المصدر والعقود والفروق، بناء debug على التخزين الخارجي، ثم تقرير عنصر→دليل. لا إضافة اختبارات آلية وفق AGENTS.md. تشغيل الجهاز وصورة المقارنة الجانبية ومعاينة النصوص والألوان للمستخدم؛ لا ادعاء مطابقة شاشة نهائية دونها. مخاطر: طول النصوص على الأجهزة الصغيرة، أنواع Room، تداخل الحفظ والإلغاء، تغيير اليوم في أثناء بقاء التطبيق مفتوحًا.

## خريطة التنفيذ

إصلاح A1 → أصل الصورة والخط والأيقونات → state يتابع Room → مكونات التصميم → الشاشات/المحررات → بناء debug وتصحيح أخطائه → تحديث CURRENT_STATE ومقارنة البنود أعلاه.

### الفحوص الفعلية

- `:app:assembleDebug :app:lintDebug` نجحا على JDK 24.0.2 وGradle 8.14.3، الناتج Debug APK نحو 12 MB، minSdk 26 / targetSdk 36.
- آخر lint: 0 أخطاء و10 تحذيرات (9 إشعارات إصدارات أحدث وواحد لشكل أيقونة launcher المقتبسة من iOS). لم تُضف baseline أو تُخفَ فحوص أو تُحدّث dependencies لتسكيت تحذيرات.
- `git diff --check` بلا مشاكل؛ `apksigner verify --verbose` أكد توقيع v2؛ `aapt dump badging` أكد اسم مهامي وMainActivity والنطاقات المذكورة.
- فحص نقل الأصول: pathData للأيقونات الأحد عشر ومَساري primary/bar مطابق للمصدر؛ hash صورة الترحيب مطابق لـ iOS.
- لا اختبارات آلية أُضيفت أو شُغلت. lint يولّد نماذج test source sets تلقائيًا لكنه لا يشغّل اختبارات.
- لم يُثبّت أو يُشغّل التطبيق، ولم تُلتقط شاشة runtime. المقارنة الجانبية وقبول الضوء/الظلام والنصوص على الهاتف تبقى للمستخدم وفق AGENTS.md؛ الصورة المولدة لا تُعد screenshot.

### أمر إعادة البناء

```sh
GRADLE_USER_HOME=/Volumes/Hussein/DevStorage/Gradle/user-home \
ANDROID_HOME=/Volumes/Hussein/DevStorage/Android/sdk \
./android/gradlew -p android :app:assembleDebug :app:lintDebug \
-Pkotlin.compiler.execution.strategy=in-process
```

الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`. الـ Gradle cache وbuild outputs على الهارد الخارجي. يُستخدم in-process لتجنب تعارض Kotlin daemon القديم الذي ظهر في الجلسة (ClassNotFoundException داخل incremental RMI)؛ لم تُقتل أي عمليات عامة ولم تتغير نسخ الأدوات.
